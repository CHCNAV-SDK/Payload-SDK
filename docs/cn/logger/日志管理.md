# 日志管理
PSDK 日志管理相关功能的头文件为 chcnav_logger.h，本文档描述了 chcnav_logger.h 文件中宏定义、枚举、结构体和函数原型的关键信息和使用方法。

- 宏定义
  * CHCNAV_LOGGER_CONSOLE_MAX_NUM
  * CHCNAV_LOGGER_MAX_USER_LOG_LEN
- 枚举
  * CHCNAV_LOGGER_CONSOLE_LOG_LEVEL_E
- 结构体
  * CHCNAV_LOGGER_CONSOLE_STRUCT

## 宏定义
### CHCNAV_LOGGER_CONSOLE_MAX_NUM
  最多同时注册的 console 数量。
  ```
    #define CHCNAV_LOGGER_CONSOLE_MAX_NUM  8
  ```
### CHCNAV_LOGGER_MAX_USER_LOG_LEN
  用户日志正文（`fmt` 展开后）的最大长度，单位：字节。超过则截断后仍输出；前缀（相对时间、模块名、等级）不计入该限制。
  ```
    #define CHCNAV_LOGGER_MAX_USER_LOG_LEN  256
  ```
### 日志输出宏
| 接口 | 功能说明 |
|---------------|----------|
| CHCNAV_LOG_DEBUG() | 输出 Debug 级别的日志信息 |
| CHCNAV_LOG_INFO() | 输出 Info 级别的日志信息 |
| CHCNAV_LOG_WARN() | 输出 Warn 级别的日志信息 |
| CHCNAV_LOG_ERROR() | 输出 Error 级别的日志信息 |

## 枚举
### CHCNAV_LOGGER_CONSOLE_LOG_LEVEL_E
  Console 与日志等级。数值越大越严重；仅当消息等级 **≥** console 配置等级时输出到该 console。
  ```
    typedef enum {
        CHCNAV_LOGGER_CONSOLE_LOG_LEVEL_DEBUG = 0,
        CHCNAV_LOGGER_CONSOLE_LOG_LEVEL_INFO  = 1,
        CHCNAV_LOGGER_CONSOLE_LOG_LEVEL_WARN  = 2,
        CHCNAV_LOGGER_CONSOLE_LOG_LEVEL_ERROR = 3,
    } CHCNAV_LOGGER_CONSOLE_LOG_LEVEL_E;
  ```

## 结构体
### CHCNAV_LOGGER_CONSOLE_STRUCT
  注册到 logger 的 console。
  ```
    typedef struct {
        CHCNAV_LOGGER_CONSOLE_FUNC func;                 /* 输出回调 */
        CHCNAV_LOGGER_CONSOLE_LOG_LEVEL_E console_level; /* 该 console 允许的最低严重等级 */
    } CHCNAV_LOGGER_CONSOLE_STRUCT;
  ```
  回调原型：
  ```
    typedef chcnav_return_code_t (*CHCNAV_LOGGER_CONSOLE_FUNC)(const uint8_t *data,
                                                               uint16_t data_len);
  ```

## 函数原型
### chcnav_logger_add_console
  注册日志 console。最多 8 个；同一 `func` 重复注册时更新其等级。
### chcnav_logger_remove_console
  移除已注册 console。
