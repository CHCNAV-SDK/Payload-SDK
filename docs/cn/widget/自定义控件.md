# 自定义控件
PSDK 自定义控件相关功能的头文件为 chcnav_widget.h，本文档描述了 chcnav_widget.h 文件中宏定义、结构体和函数原型的关键信息和使用方法。
- 宏定义
  * CHCNAV_WIDGET_FLOATING_WINDOW_MSG_MAX_LEN
- 枚举
  * CHCNAV_WIDGET_TYPE_E
  * CHCNAV_WIDGET_BUTTON_STATE_E
  * CHCNAV_WIDGET_SWITCH_STATE_E
- 结构体
  * CHCNAV_WIDGET_FILE_BINARY_ARRAY_STRUCT
  * CHCNAV_WIDGET_BINARY_ARRAY_CONFIG_STRUCT
  * CHCNAV_WIDGET_HANDLER_LIST_ITEM_STRUCT
- 函数原型
  * chcnav_widget_init
  * chcnav_widget_deinit
  * chcnav_register_default_widget_config_dir_path
  * chcnav_register_widget_config_by_dir_path
  * chcnav_register_default_widget_config_by_binary_array
  * chcnav_register_widget_config_by_binary_array
  * chcnav_register_widget_handler_list
  * chcnav_floating_window_show_message


## 宏定义
### CHCNAV_WIDGET_FLOATING_WINDOW_MSG_MAX_LEN
  浮窗消息的最大长度，单位：字节。
  ```
    #define CHCNAV_WIDGET_FLOATING_WINDOW_MSG_MAX_LEN  255
  ```

## 枚举
### CHCNAV_WIDGET_TYPE_E
  自定义控件类型
  ```
    typedef enum {
        CHCNAV_WIDGET_TYPE_BUTTON = 1,      /* 按钮 */
        CHCNAV_WIDGET_TYPE_SWITCH = 2,      /* 开关 */
        CHCNAV_WIDGET_TYPE_SCALE = 3,       /* 滑条 */
        CHCNAV_WIDGET_TYPE_LIST = 4,        /* 列表 */
        CHCNAV_WIDGET_TYPE_INT_INPUT = 5,   /* 整型输入框 */
    } CHCNAV_WIDGET_TYPE_E;
  ```
### CHCNAV_WIDGET_BUTTON_STATE_E
  按钮控件状态
  ```
    typedef enum {
        CHCNAV_WIDGET_BUTTON_STATE_RELEASE_UP = 0, /* 按钮抬起 */
        CHCNAV_WIDGET_BUTTON_STATE_PRESS_DOWN = 1, /* 按钮按下 */
    } CHCNAV_WIDGET_BUTTON_STATE_E;
  ```
### CHCNAV_WIDGET_SWITCH_STATE_E
  开关控件状态
  ```
    typedef enum {
        CHCNAV_WIDGET_SWITCH_STATE_OFF = 0, /* 关闭 */
        CHCNAV_WIDGET_SWITCH_STATE_ON = 1,  /* 打开 */
    } CHCNAV_WIDGET_SWITCH_STATE_E;
  ```

## 结构体
### CHCNAV_WIDGET_FILE_BINARY_ARRAY_STRUCT
  Widget 二进制数组控件文件。
  ```
    typedef struct {
        char *file_name;                  /* 文件名 */
        uint32_t file_size;               /* 文件大小，单位：byte */
        const uint8_t *file_binary_array; /* 文件二进制 C 数组 */
    } CHCNAV_WIDGET_FILE_BINARY_ARRAY_STRUCT;
  ```
### CHCNAV_WIDGET_BINARY_ARRAY_CONFIG_STRUCT
  Widget 自定义控件二进制数组配置文件。
  ```
    typedef struct {
        uint16_t binary_array_count;                               /* 二进制数组控件文件数量 */
        CHCNAV_WIDGET_FILE_BINARY_ARRAY_STRUCT *file_binary_array_list; /* 二进制数组控件文件列表 */
    } CHCNAV_WIDGET_BINARY_ARRAY_CONFIG_STRUCT;
  ```
### CHCNAV_WIDGET_HANDLER_LIST_ITEM_STRUCT
  控件项处理函数
  ```
    typedef struct {
        uint32_t widget_index;   /* 自定义控件索引，从 0 开始编号，不可重复 */
        CHCNAV_WIDGET_TYPE_E widget_type; /* 控件类型，参考 CHCNAV_WIDGET_TYPE_E */
        /**
         * @brief 设置控件值
         * @param widget_type: 控件类型
         * @param index: 控件索引
         * @param value: 控件值
         * @param user_data: 用户数据指针
         * @return 执行结果
         */
        chcnav_return_code_t (*set_widget_value)(CHCNAV_WIDGET_TYPE_E widget_type, uint32_t index,
                                                 int32_t value, void *user_data);
        /**
         * @brief 获取控件值
         * @param widget_type: 控件类型
         * @param index: 控件索引
         * @param value: 输出，控件值
         * @param user_data: 用户数据
         * @return 执行结果
         */
        chcnav_return_code_t (*get_widget_value)(CHCNAV_WIDGET_TYPE_E widget_type, uint32_t index,
                                                 int32_t *value, void *user_data);
        void *user_data; /* 用户数据指针 */
    } CHCNAV_WIDGET_HANDLER_LIST_ITEM_STRUCT;
  ```

## 函数原型
### chcnav_widget_init
  初始化自定义控件模块。使用任何 Widget 功能前须先调用本接口。
### chcnav_widget_deinit
  反初始化自定义控件模块，释放模块分配的资源。
### chcnav_register_default_widget_config_dir_path
  注册自定义控件配置文件默认的路径。
  - 仅基于linux开发的负载设备支持使用本接口；
  - 在linux操作系统中可使用chcnav_register_default_widget_config_dir_path()和chcnav_register_widget_config_by_dir_path()函数设置自定义控件配置文件的路径；
  - 当不需要自定义控件配置支持多语言时，只需使用chcnav_register_default_widget_config_dir_path()注册控件的配置文件；
  - 需要支持多语言时，必须使用chcnav_register_widget_config_by_dir_path()指定特定语言的控件配置，如果没有对应语言的控件配置，则使用chcnav_register_default_widget_config_dir_path()注册的配置文件。
### chcnav_register_widget_config_by_dir_path
  注册自定义控件配置文件的路径。
  - 仅基于linux开发的负载设备支持使用本接口；
  - 不同语言的控件配置需要有相同的控件类型，索引和数量。
### chcnav_register_default_widget_config_by_binary_array
  通过二进制数组控件文件注册默认控件配置。
  - 仅基于RTOS开发的负载设备支持使用本接口；
  - 在RTOS系统中可使用该接口和chcnav_register_widget_config_by_binary_array()接口设置控件配置参数；
  - 若没有使用chcnav_register_widget_config_by_binary_array()注册与系统语言对应的控件配置信息时，将使用此函数中的配置信息。
### chcnav_register_widget_config_by_binary_array
  通过二进制数组控件文件注册控件配置信息。
  - 仅基于RTOS开发的负载设备支持使用本接口；
  - 不同语言的控件配置需要有相同的控件类型，索引和数量。
### chcnav_register_widget_handler_list
  注册自定义控件处理函数列表。
### chcnav_floating_window_show_message
  向SmartGo或基于MSDK开发的移动端App的浮窗发送消息。
