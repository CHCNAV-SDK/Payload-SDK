# Flight Control
This document describes the key information and usage of structures and function prototypes in the `chcnav_flight_controller.h` file.

## Function
### chcnav_flight_controller_init()
    Initialize flight control functionality.
### chcnav_flight_controller_arm()
    Arm (unlock motors).
### chcnav_flight_controller_disarm()
    Disarm (lock motors).
### chcnav_flight_controller_start_take_off()
    Take off.
### chcnav_flight_controller_start_waypoint()
    Start waypoint mission.
### chcnav_flight_controller_pause()
    Pause.
### chcnav_flight_controller_start_go_home()
    Return to home.
### chcnav_flight_controller_start_landing()
    Land.
### chcnav_flight_controller_deinit()
    Deinitialize flight control functionality.
