CHCNAV provides the Payload SDK (PSDK) development toolkit to help developers build payload devices that can be mounted on CHCNAV drones. PSDK lets developers use onboard resources such as power, communication links, and status information to develop payloads for CHCNAV aircraft. Based on industry application requirements, developers can use the functional interfaces provided by PSDK, together with structural design, hardware design, software logic, and algorithm optimization, to build payloads for specialized domains—such as automated inspection systems, infrared cameras, mapping cameras, multispectral cameras, loudspeakers, searchlights, and more.
# Key Features
- Developed in C++
- Supports mainstream embedded systems such as Linux and RTOS
- Modular design for easy cross-platform porting
