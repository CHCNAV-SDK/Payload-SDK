# chcnav_psdk_tool

chcnav_psdk_tool runs on Windows 10/11. It helps developers adapt payloads to the CHCNAV aircraft system by detecting devices, connecting, and getting or setting features.

The communication protocol used by chcnav_psdk_tool matches the protocol supported by CHCNAV aircraft. If you can connect and control a payload with chcnav_psdk_tool, the CHCNAV aircraft system can connect and control that payload in the same way.

## Usage

Open the tool, select the **COM port** that connects the payload to the PC at the top of the window, then click **Open**. You can then develop and debug according to the payload type.
